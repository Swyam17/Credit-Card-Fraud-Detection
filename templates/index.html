Public Deployment & REST API Reference

Anyone with your deployed link can access this portal and use the REST API

Deploy Free to Render.com

  1. Push this repository to your GitHub account.
  2. Go to Render.com > Click New + > Web Service.
  3. Select your repository. Render automatically reads Procfile and render.yaml.
  4. Click Deploy Web Service. You get a public URL like https://your-app.onrender.com!

Deploy to Hugging Face Spaces

  1. Create a new Space on Hugging Face with SDK: Docker or Blank.
  2. Push or upload repository files. The included Dockerfile runs app.py on port 7860/5000 automatically.
  3. Your app is live with a permanent, public HTTPS link!

Real-time Prediction Endpoint

POST /api/predict

Send transactional parameters as JSON to receive instant fraud classification and risk score.

Sample cURL Request
curl -X POST https://YOUR_DEPLOYED_URL/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 3400.00,
    "hour": 3,
    "merchant_category": "Luxury & Jewelry",
    "distance": 850.0,
    "is_foreign": 1,
    "failed_pin": 2,
    "device_trust": 25
  }'
Sample JSON Response

  "success": true,
  "prediction": {

    "fraud_probability": 0.964,
